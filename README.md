# 📚 Plataforma de Cursos Gratuitos - CursosTop

![Preview da Plataforma](public/preview.png)

Uma plataforma moderna que reúne os melhores cursos gratuitos do YouTube, organizados por categorias para facilitar seu aprendizado.

## ✨ Funcionalidades

- 🎯 Catálogo com **12 categorias** de cursos
- 📹 Player integrado de vídeos do YouTube
- 🔍 Interface intuitiva e responsiva
- 🌗 Modo claro e escuro
- 📄 Geração de certificado personalizado
- 🔒 Autenticação com NextAuth

## 🚀 Tecnologias Utilizadas

- **Next.js** - Framework React para construção da aplicação
- **TypeScript** - Tipagem estática para maior segurança
- **Tailwind CSS** - Estilização utilitária
- **shadcn/ui** - Componentes UI acessíveis e modernos
- **NextAuth** - Sistema de autenticação
- **jsPDF** - Geração de certificados em PDF

## 🛠️ Como Executar Localmente

1. **Clone o repositório**
   ```bash
   git clone https://github.com/seu-usuario/plat-cursos.git
   cd plat-cursos
   ```

2. **Instale as dependências**
   ```bash
   npm install
   # ou
   yarn install
   ```

3. **Configure as variáveis de ambiente**
   Crie um arquivo `.env.local` baseado no `.env.example`

4. **Inicie o servidor de desenvolvimento**
   ```bash
   npm run dev
   # ou
   yarn dev
   ```

5. **Acesse a aplicação**
   Abra [http://localhost:3000](http://localhost:3000) no seu navegador
